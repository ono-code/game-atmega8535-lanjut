Dasar Arsitektur Register & Hardware untuk Siswa Kelas 11 TEI

Register Utama (DDR, PORT, PIN)

Mikrokontroler AVR memiliki 3 register kunci untuk mengatur setiap Port I/O:

  • DDRx: Menentukan Arah Data (0 = Input, 1 = Output).
  • PORTx: Mengeluarkan sinyal logika High (1/5V) atau Low (0/0V).
  • PINx: Membaca logika sinyal masukan dari luar (Saklar/Sensor).
Perintah Sintaks BASCOM-AVR

Bahasa BASIC pada BASCOM-AVR sangat mudah dibaca karena mirip bahasa manusia:

  • $regfile = "m8535.dat" (Deklarasi chip)
  • $crystal = 8000000 (Frekuensi clock 8MHz)
  • Config Portb = Output (Port B jadi keluaran)
  • Set Portb.0 / Reset Portb.0 (HIGH / LOW)
Struktur Port ATmega8535

ATmega8535 memiliki kemasan DIP 40 Pin dengan 4 buah Port 8-bit (PORTA, PORTB, PORTC, PORTD):

  • PORTA (Pin 33-40): I/O Digital + Input ADC Analog.
  • PORTB (Pin 1-8): I/O Digital + SPI + Timer/Counter.
  • PORTC (Pin 22-29): I/O Digital + JTAG + I2C.
  • PORTD (Pin 14-21): I/O Digital + Komunikasi USART (TX/RX).

Kamus Perintah Cepat BASCOM-AVR

Referensi cepat sintaks penting untuk praktikum laboratorium elektronika industri.

$regfile = "m8535.dat"

Menentukan berkas header definisi register spesifik untuk chip ATmega8535.

$crystal = 8000000

Memberitahu kompilator frekuensi osilator kristal eksternal yang terpasang (8 MHz).

Config Portb = Output / Input

Mengatur seluruh 8 pin pada PORTB sebagai saluran keluaran (Output) atau masukan (Input).

Set Portb.0 / Reset Portb.0

Mengubah logika pin individual: Set = HIGH (5V), Reset = LOW (0V).

Wait 1 / Waitms 500

Memberikan jeda waktu penundaan (delay) dalam hitungan detik (Wait) atau milidetik (Waitms).

Do ... Loop

Membuat perulangan tanpa henti (infinite loop) dalam program utama mikrokontroler.

Cls : Lcd "Halo TEI"

Cls membersihkan layar LCD, Lcd menampilkan teks pada baris aktif.

Lowerline

Pindahkan kursor penulisan LCD ke baris kedua (baris bawah) pada LCD 16x2.
